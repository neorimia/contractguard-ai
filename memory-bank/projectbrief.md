# Project Brief - ContractGuard AI

## Core Mission

Build an AI-powered smart contract security scanner that detects scams, honeypots, and rug pulls in seconds. Launch during the current bull market window (3-6 months) to capitalize on peak security concerns and user willingness to pay for protection.

## Primary Goals

1. **Ship MVP in 14 days** - Aggressive timeline to capture bull market window
2. **Generate revenue by Week 3** - Implement freemium model with $29/month Pro tier
3. **Hit $5-10k MRR in 3 months** - Scale to profitable SaaS business
4. **Fund future projects** - Use profits to build NeoFit or other passion projects

## Core Value Proposition

"Grammarly for smart contracts - paste any contract address, get instant AI security analysis in plain English"

## Target Users

- **Primary:** Crypto traders (degen traders, cautious investors) - 90% of market
- **Secondary:** Developers/Whales - 10% of market (higher value, API access)
- **Pain Point:** 99% can't read Solidity code, losing $5k-50k per scam

## Key Differentiators

1. **AI-powered explanations** - Not just scores, but plain English explanations
2. **Natural language output** - "Only owner can sell" vs technical jargon
3. **Viral shareability** - Beautiful share cards for social media
4. **Speed** - <10 seconds vs 30-60 seconds for competitors
5. **First-mover advantage** - No existing AI-powered contract auditors

## Success Metrics

- **Week 1:** 1,000+ visitors, 500+ scans, 5+ Pro signups
- **Month 1:** 10,000+ visitors, 5,000+ scans, 50+ Pro users ($1,450 MRR)
- **Month 3:** 50,000+ visitors, 25,000+ scans, 200+ Pro users ($5,800 MRR)

## Technical Requirements

- Next.js 15 + TypeScript (existing expertise)
- Neon PostgreSQL + Drizzle ORM (serverless, scalable)
- OpenAI GPT-4 Turbo (AI analysis)
- Etherscan + Alchemy APIs (blockchain data)
- Vercel deployment (zero-config, edge-optimized)
- Stripe payments (Week 3)

## Business Model

- **Free Tier:** 3 scans/day, basic analysis
- **Pro Tier:** $29/month, unlimited scans, API access
- **Enterprise:** Custom pricing, white-label options

## Risk Mitigation

- **Bull market ends:** Ship fast (2 weeks), add utility features
- **Competition copies:** First-mover advantage, build brand quickly
- **AI costs spike:** Aggressive caching, multiple providers
- **Low conversion:** A/B testing, improve UX, add features

## Project Scope

**Phase 1 (Weeks 1-2):** MVP with core functionality
**Phase 2 (Week 3):** Monetization with Stripe integration
**Phase 3 (Months 2-3):** Scale to $5-10k MRR
**Phase 4 (Month 4+):** Decide on NeoFit vs ContractGuard expansion

## Success Criteria

- Working AI analysis in <10 seconds
- Beautiful, shareable results
- 2-5% free-to-paid conversion rate
- Positive unit economics (LTV/CAC >3x)
- Product-market fit signals by Month 1

## Constraints

- **Time:** Must ship in 14 days to capture bull market
- **Budget:** <$100 initial costs, bootstrap approach
- **Team:** Solo developer (me)
- **Market:** Bull market window (3-6 months max)

## Decision Framework

This project was chosen over NeoFit because:

1. **Timing:** Bull market window is NOW vs evergreen fitness market
2. **Speed:** 2-week MVP vs 3-6 month MVP
3. **Revenue:** $150k-600k Year 1 vs $20k-100k Year 1
4. **Validation:** Know if it works in weeks vs months
5. **Skills transfer:** AI integration skills help all future projects
