# Startup Template 

## Development

1. Install dependencies:
```bash
npm install
# or
yarn install
```

2. Run the development server:
```bash
npm run dev
# or
yarn dev
```

3. Open [http://localhost:3000](http://localhost:3000) to view the site.

## Tech Stack

- Next.js 15
- React
- TypeScript
- TailwindCSS v4
- Motion
- Lucide Icons
